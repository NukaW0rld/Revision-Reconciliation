```ini
autostart=true
autorestart=true
```

<!-- RESEARCH.md: why --worker-type=thread -->
# Thread workers share process memory (SQLAlchemy connections)
# --workers=1 is sufficient for single-run-at-a-time shop workflow
# Process workers would require separate DB connection setup

<!-- RESEARCH.md: HUEY_DB path -->
# Absolute path required: /app/data/huey.db
# Must match Docker volume mount at /app/data
# Set via HUEY_DB env var (shop/tasks.py reads it)
