  <read_first>delta_preservation/reconcile/classify.py, delta_preservation/cli.py, assets/debug_report_part8.json, .planning/phases/06-added-characteristic-detection-and-snippet-accuracy/06-CONTEXT.md</read_first>
  <action>
Add an explained-by-match suppressor in `classify.py` and then consume the grouped evidence in `cli.py`.

Suppressor contract:
- Build grouped signatures for already matched annotations on the same page
- A candidate added row is suppressible only when both of these are true:
  1. the candidate grouped text is a semantic or normalized-text subset already present in a matched annotation group
  2. the candidate grouped bbox sits inside, strongly overlaps, or is otherwise owned by the matched annotation bbox
- Do not suppress on geometry alone
- Record a human-readable reason when suppression fires so the behavior is inspectable in debug output

Packet assembly contract in `cli.py`:
- when `delta_internal.status == "added"` and `added_requirement_text` exists, use it as `requirement_revB`
- when `added_bbox` exists, use it as the base Rev B bbox before coverage expansion
- when grouped evidence contains multiple spans or a grouped bbox larger than the seed span, emit `snippet_rule_family="grouped_callout"`
- keep backward-compatible fallback behavior only for legacy internal items that do not populate the new fields
</action>
