Create `tests/conftest.py` with two pytest fixtures:

**`db_engine` (scope="function"):** Creates an in-memory SQLite engine using `StaticPool` so the same connection is reused within a test. Calls `Base.metadata.create_all(engine)` to create all tables. Yields the engine. Calls `Base.metadata.drop_all(engine)` in teardown.

```python
from sqlalchemy import create_engine, StaticPool
from sqlalchemy.orm import sessionmaker
from shop.app import create_app
from shop.database import Base
from shop.dependencies import get_db

@pytest.fixture(scope="function")
def db_engine():
    engine = create_engine(
        "sqlite://",
        connect_args={"check_same_thread": False},
        poolclass=StaticPool,
    )
    Base.metadata.create_all(engine)
    yield engine
    Base.metadata.drop_all(engine)
```

**`client` (scope="function"):** Receives `db_engine`. Creates `TestingSessionLocal = sessionmaker(bind=db_engine)`. Defines `override_get_db()` generator. Calls `create_app()`, sets `app.dependency_overrides[get_db] = override_get_db`. Yields `TestClient(app, raise_server_exceptions=True)`.

Also add an `admin_user` fixture (scope="function") that receives `db_engine` and seeds a User row with `email="admin@shop.local"`, `hashed_password=hash_password("changeme")`, `role="admin"`, `is_active=True`. Returns the user object. This is used by auth tests.

Add a `shop_config` fixture that inserts a `ShopConfig` row with `setup_complete=False, wizard_step=0` so tests start in the pre-setup state.

Import: `import pytest`, `from fastapi.testclient import TestClient`. Import `hash_password` from `shop.services.auth` (will exist after Plan 02).

Use `# noqa: E402` where needed to silence import order lint errors. The file will have failing imports until `shop/` exists — that's expected; this is a scaffold.
