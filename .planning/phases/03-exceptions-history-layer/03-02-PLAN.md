## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Active accepted-alternate history -> evaluator | DB-backed reusable history influences packet conformance and must remain scoped, normalized, and conservative. |
| Evaluator metadata -> `debug_report.json` | History-derived conformance flows into exported evidence and must stay auditable rather than looking like a canonical truth match. |
| Task-side DB load -> standalone-capable pipeline | Web-tier loading of alternates must not couple `delta_preservation` directly to SQLAlchemy. |
