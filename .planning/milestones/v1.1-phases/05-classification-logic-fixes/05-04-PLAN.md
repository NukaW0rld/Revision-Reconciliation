  <files>delta_preservation/reconcile/classify.py</files>
  <read_first>delta_preservation/reconcile/classify.py, delta_preservation/reconcile/anchors.py, delta_preservation/reconcile/normalize.py, .planning/phases/05-classification-logic-fixes/05-RESEARCH.md, .planning/phases/05-classification-logic-fixes/05-REVIEWS.md</read_first>
  <action>
Edit `delta_preservation/reconcile/classify.py` as follows.

1. Extend the internal `DeltaItem` dataclass with three additive, internal-only fields:
- `added_requirement_text: Optional[str] = None`
- `added_bbox: Optional[Tuple[float, float, float, float]] = None`
- `added_page: Optional[int] = None`

2. Populate those fields in every `status="added"` constructor:
- GD&T grouped item: `added_requirement_text=group_text`, `added_bbox=union of group span bboxes`, `added_page=0`
- stacked-limits pair: `added_requirement_text=pair_text`, `added_bbox=union of the pair bboxes`, `added_page=0`
- standard unmatched span: `added_requirement_text=span.text`, `added_bbox=span.bbox_pdf`, `added_page=0`

3. Add `reconcile_removed_added_pairs(items: List[DeltaItem], anchors: List[Anchor]) -> List[DeltaItem]` with this exact contract:
- Build `anchor_by_char_no`.
- Only consider `removed` items with a matching anchor and `added` items with `added_bbox` and `added_page`.
- Removed-side point = centroid of `anchor.req_bbox` if present, otherwise centroid of `anchor.balloon_bbox`.
- Added-side point = centroid of `added_bbox`.
- Require `anchor.page == added_page`.
- Require Euclidean distance <= `CLS02_MAX_DISTANCE_PT = 150.0`.
- Use `classify_requirement_type(anchor.requirement_raw)` and `classify_requirement_type(added_requirement_text or added_span.text)` for the type gate.
- Resolve one-to-one by nearest compatible added item.
- Rewrite the removed item in place: `status="changed"`, keep `char_no`, attach the paired `added_span`, append reconciliation reasons, and raise confidence to at least `0.70`.
- Return a new list that omits consumed added items.

Do not persist the new internal-only metadata to the Pydantic packet in this phase.
</action>
  <acceptance_criteria>
    - `rg -n "added_requirement_text|added_bbox|added_page|CLS02_MAX_DISTANCE_PT|def reconcile_removed_added_pairs" delta_preservation/reconcile/classify.py` returns the new contract.
    - `rg -n "status=\\\"changed\\\"|reconciled removed\\+added pair|0\\.70" delta_preservation/reconcile/classify.py` returns the in-place rewrite behavior.
    - `pytest tests/test_classify_bugfixes.py::TestRemovedAddedReconciliation -x` exits 0.
  </acceptance_criteria>
