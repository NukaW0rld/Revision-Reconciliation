Implementation contract:
- Add `_ASYMMETRIC_SHAPE_RE` with support for both standard decimals and leading decimals, for example `+.005 / -.003`.
- Add a small helper such as `_is_symmetric_to_asymmetric_kind_change(tolerance_comparison)` that returns True when one side is `plus_minus` and the other side is `bilateral_stacked` or `unilateral_stacked`.

- Preserve the existing `tolerances_differ` behavior for same-kind changes.

- When `tolerance_comparison is None`, compare `anchor.requirement_raw` and the matched Rev B text with `±` detection versus `_ASYMMETRIC_SHAPE_RE`.
- If Rev A is symmetric and Rev B is asymmetric, promote `unchanged` or `uncertain` to `changed`.
- Never change `status="changed"` back to `unchanged` in the fallback path.
</action>
