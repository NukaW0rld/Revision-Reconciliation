# Milestone v1.1: Cross-part Characteristic Matching Refinement

**Status:** ✅ SHIPPED 2026-04-19
**Phases:** 4-12
**Total Plans:** 32

## Overview

This milestone fixed concrete algorithm errors across the 9-part debug corpus to improve aggregate classification accuracy. Every fix was required to generalize across all parts — no per-part hacks. Ground truth files remained canonical and were never edited by the pipeline. The milestone also closed all process-artifact and verification gaps, proved the live web workflow end-to-end, and gated sign-off on unresolved debug exceptions.

## Milestone Summary

**Key Decisions:**

- Every algorithm fix must generalize across all 9 debug-corpus parts — no per-part hacks
- Ground truth files are canonical references and must never be auto-edited by the pipeline
- Use `confidence_flags` as packet-native advisory data rather than re-deriving from reasons text
- Replace ±200 pt same-row sweep with fixed-point `_spans_are_annotation_companions` walk
- `advisory_flags_by_item_id` keys by `ReviewItem.id` (not `char_no`) to tolerate duplicate/None characteristic numbers
- `build_signoff_gate_state` uses strict `review_needed` exception contract to avoid false positives
- Signed debug snapshot at sign-off time becomes the single source of truth for export
- Use `pytest tmp_path` for pipeline output dirs in E2E tests for artifact persistence

**Issues Resolved:**

- GD&T compact token splitting, word-form normalization, composite frame capture
- Adjacency bleed false positives, removed+added pair reconciliation, asymmetric tolerance detection
- Missing added characteristics across the 9-part corpus (7/35 → 33/35 truth rows claimed)
- Title block regions leaking into characteristic search windows
- Hidden missing-added-truth blockers allowing premature export
- Missing VERIFICATION.md for Phases 4, 8, and 11
- Stale Nyquist VALIDATION.md flags across 4 phases

**Issues Deferred:**

- Part 5 indexes 16+17: thread/countersink matching-layer architectural deferrals (see 09-02-SUMMARY.md)
- Part 9 truth_index 42 (`⏥ .01`): explained-by-match suppressor false absorption (see debug/resolved/phase06-part9-flatness-miss.md)
- Composite GD&T with positional-zone modifiers (Part 9 multi-datum advanced FCFs)
- Cross-part contradiction detection between accepted alternates

**Technical Debt Incurred:**

- SUMMARY.md frontmatter across all phases lacks `requirements_completed` field (project convention divergence)
- v1.0 Phases 1-2 still missing VERIFICATION.md artifacts (carried forward from v1.0 tech debt)
